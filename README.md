# RetroTV — эмулятор NES / SNES / Sega Mega Drive для Android TV (TCL)

Приложение для телевизора: список игр на главном экране, справа вверху кнопки
«＋» (добавить ром) и «настройки», игра геймпадом DualSense (PS5), меню паузы с
фильтрами картинки, сохранением/загрузкой и выходом, перемотка на удержании R2.

Эмуляцию выполняют проверенные open-source ядра libretro (FCEUmm, Snes9x,
Genesis Plus GX) — те же, что в RetroArch. Приложение — обвязка вокруг них
через библиотеку LibretroDroid.

---

## 1. Как собрать APK

Собирается на компьютере в Android Studio (на самом ТВ ничего собирать не нужно).

1. Установите **Android Studio** (Hedgehog или новее), откройте папку проекта
   `RetroTV` («Open»). Студия сама скачает Gradle и зависимости.

2. **Скачайте ядра эмуляции** (3 файла, каждый ~1–3 МБ) с официального
   сборочного сервера libretro:

   64-бит (новые TCL): `https://buildbot.libretro.com/nightly/android/latest/arm64-v8a/`
   32-бит (старые TCL): `https://buildbot.libretro.com/nightly/android/latest/armeabi-v7a/`

   Нужны архивы:
   - `fceumm_libretro_android.so.zip` (NES)
   - `snes9x_libretro_android.so.zip` (SNES)
   - `genesis_plus_gx_libretro_android.so.zip` (Sega Mega Drive)

   Распакуйте и **переименуйте**:

   | Скачанный файл | Новое имя |
   |---|---|
   | fceumm_libretro_android.so | `libfceumm.so` |
   | snes9x_libretro_android.so | `libsnes9x.so` |
   | genesis_plus_gx_libretro_android.so | `libgenesis.so` |

   Положите их в:
   - `app/src/main/jniLibs/arm64-v8a/` (64-битные версии)
   - `app/src/main/jniLibs/armeabi-v7a/` (32-битные версии)

   Ядра пакуются прямо внутрь APK — это сделано специально для безопасности:
   приложение ничего не скачивает на телевизор и не исполняет файлы из
   записываемых папок.

3. Build → **Build APK(s)**. Готовый файл:
   `app/build/outputs/apk/debug/app-debug.apk` (или release, если подпишете).

4. Установка на TCL: включите на ТВ «Настройки → Об устройстве → Сборка»
   (7 нажатий) → «Отладка по USB / по сети», либо просто скиньте APK на флешку
   и откройте файловым менеджером, разрешив установку из неизвестных источников.
   Через сеть: `adb connect IP_телевизора:5555` → `adb install app-debug.apk`.

> Если Gradle не находит LibretroDroid — проверьте актуальный номер версии на
> https://github.com/Swordfish90/LibretroDroid/releases и поправьте его в
> `app/build.gradle.kts`. При смене мажорной версии имена пары методов могли
> измениться — студия подскажет.

## 1-Б. Сборка в облаке без установки чего-либо (GitHub Actions)

Если не хочется ставить Android Studio — APK соберёт облако GitHub:

1. Зарегистрируйтесь на github.com и создайте новый **публичный** репозиторий.
2. «uploading an existing file» → перетащите в браузер всё содержимое папки
   проекта (вместе с папками `.github`, `app`, `scripts`).
3. Откройте вкладку **Actions** — сборка «Build RetroTV APK» запустится сама:
   облако скачает ядра с buildbot.libretro.com, соберёт проект и выложит
   готовый файл.
4. В завершённой сборке внизу раздел **Artifacts** → скачайте `RetroTV-apk`,
   внутри — `app-debug.apk` для установки на ТВ.

Шаг с ручным скачиванием ядер в этом случае не нужен — скрипт
`scripts/download_cores.sh` делает это автоматически.

## 2. Как добавлять игры (то, о чём ты спрашивал)

Ты понял правильно, и твой план — самый правильный и безопасный:

1. Скопируй ромы (`.nes`, `.sfc`, `.smc`, `.md`, `.gen`, `.bin`, `.smd` или
   **`.zip` с ромом внутри** — распаковывать не нужно) в общую папку телевизора — удобнее всего в **Download / Загрузки**
   (с флешки, по сети, через Send Files to TV и т.п.).
2. В приложении нажми «＋» справа вверху → откроется системный проводник →
   выбери файл.
3. Приложение **скопирует** ром в свою приватную защищённую папку
   (`/data/data/com.retrotv.emu/files/roms/...`) и добавит в список.
   Оригинал в Download можно после этого удалить.

Почему именно так, а не «читать напрямую из общей папки»:
- не нужно опасное разрешение «доступ ко всем файлам»;
- библиотека игр не сломается, если вытащить флешку или почистить Download;
- при удалении приложения все его файлы удаляются автоматически — на ТВ
  не остаётся мусора.

Удаление игры: **долгое нажатие** на игре в списке → «Удалить» (удаляется ром
и его сохранение, память освобождается).

⚠️ Юридическая заметка: используй ромы только тех игр, которыми владеешь
(собственные резервные копии картриджей) или свободно распространяемых
(homebrew). Скачивание чужих коммерческих ромов — нарушение авторских прав.

## 3. Защита памяти телевизора при загрузке ромов

То, что ты просил, встроено в импортёр (`RomImporter.kt`):

1. **Белый список форматов** — файлы с чужим расширением отклоняются сразу.
2. **Лимиты размера**: NES — 8 МБ, SNES и Sega — 16 МБ, общий потолок 32 МБ.
   Файл больше лимита не начнёт копироваться вовсе.
3. **Проверка свободного места до копирования** — если на ТВ меньше ~200 МБ
   запаса, импорт не запустится и напишет почему.
4. **Счётчик байтов во время копирования** — даже если источник «врёт» о
   размере и льёт данные бесконечно, копирование обрывается ровно на лимите.
5. **Таймаут 60 секунд** — зависшее чтение (битая флешка, сеть) прерывается.
6. **Атомарная запись**: сначала во временный `.part`-файл, потом
   переименование. Любая ошибка → временный файл удаляется, мусора нет.
7. **ZIP-архивы распаковываются потоково с тем же счётчиком байт** — «zip-бомба»
   (маленький архив, раздувающийся в гигабайты) будет остановлена на лимите,
   а архивы с сотнями файлов внутри отклоняются.
8. **Проверка сигнатуры**: у NES проверяется заголовок `NES␚`, у Sega — метка
   `SEGA`. Случайный «не-ром» не попадёт в библиотеку.
9. Всё хранится **только в приватной папке приложения** — приложение
   физически не может тронуть систему ТВ или чужие файлы.

## 4. Управление (DualSense / PS5)

Подключи геймпад к ТВ по Bluetooth (на DualSense зажми **PS + Share** до
мигания подсветки, затем на ТВ: Настройки → Пульты и аксессуары → Добавить).

| Кнопка PS5 | Действие |
|---|---|
| Крестовина / левый стик | Движение (D-pad консоли) |
| ✕ (крест) | A / основная кнопка |
| ○ (круг) | B |
| □ / △ | X / Y (SNES), C и др. (Sega) |
| L1 / R1 | L / R (SNES), X/Z (Sega) |
| Options | Start |
| Create (Share) | Select |
| **R2 (нажать)** | **Прыжок назад на ~10-20 секунд** (можно выключить в настройках) |
| **L2** | **Меню паузы** (сохранить/загрузить/фильтр/выход) |
| L3 + R3 вместе | Меню паузы (запасной вариант) |
| Кнопка «назад» на пульте ТВ | Тоже меню паузы |

Кнопка PS зарезервирована системой Android — на неё повесить паузу нельзя,
поэтому выбрано сочетание L3+R3: его невозможно нажать случайно, и оно не
занято ни в одной игре этих консолей.

## 5. Меню паузы

L3+R3 → эмуляция и звук останавливаются, появляется меню:

- **Продолжить**
- **Сохранить / Загрузить** — мгновенное сохранение состояния (свой слот у
  каждой игры). Плюс обычные внутриигровые сохранения (батарейка картриджа)
  пишутся автоматически.
- **Фильтр картинки** — по кругу: *Чёткие пиксели → Сглаживание (апскейл) →
  CRT (кинескоп) → LCD*. При смене фильтра игра незаметно перезапустится и
  продолжится с того же кадра.
- **Выйти в меню** — на главный экран приложения.

## 6. Настройки (шестерёнка)

- Фильтр картинки по умолчанию;
- сколько памяти занимают игры и сохранения + сколько свободно на ТВ;
- кнопка «Удалить все сохранения».
