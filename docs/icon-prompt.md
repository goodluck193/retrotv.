# Icon asset

Created with the built-in image generation tool, then resized for Android packaging. No branded console symbol or game character was requested.

Final assets: `app/src/main/res/drawable-nodpi/console_mark.png` (256 px) and `tv_banner.png` (320 × 180). The banner adds the app name with DejaVu Sans. The Android adaptive icon uses an inset to keep the mark inside launcher masks.

Prompt: “A beautiful minimalist original icon for Retro Console: a single bold geometric retro game controller / console mark, cyan on a uniform dark navy square background, one small warm orange button. Balanced flat shapes, clean rounded contours, recognizable at 48 pixels. Center the mark with empty margins for Android circular masking. No lettering, shadows, gradients, border, mockup, Nintendo / Sony / Sega symbols, or game characters.”

Refinement: remove glow, halos, noise and texture; use a flat navy background, cyan silhouette and orange accent, with wide margins and no extra symbols.
